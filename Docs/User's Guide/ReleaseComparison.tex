\section{Comparison results}
This section reports the verification-model comparison for the current \mut\ release against the previous-version baseline. Each figure is one frame from \texttt{BatchComparisonPlots.lay}: solid lines are the current run, dashed lines are the baseline. Coincident lines mean the responses match.

Current volume-budget \texttt{MUTVersion}: \texttt{2025.026 RELEASE}.
Baseline volume-budget \texttt{MUTVersion}: \texttt{2025.012 RELEASE}.

exported 16/16 PNG file(s) via C:\textbackslash{}Program Files\textbackslash{}Tecplot\textbackslash{}Tecplot 360 EX 2018 R2\textbackslash{}bin\textbackslash{}tec360.EXE.

Numeric status uses the ASCII volume-budget \texttt{IN - OUT} series, compared
record-by-record when both files list the same \texttt{TOTAL TIME} values.
\mfus\ often writes several budget dumps at the same time at a stress-period
boundary. Comparing by interpolated time would pair later dumps with the first
dump at that time and can false-flag models such as
\texttt{6\_Abdul\_Prism\_Cell}. With index-wise comparison those examples match
the 2025.012 baseline bit-for-bit (349 records, max $|$diff$|$ of 0).

The only remaining differences versus 2025.012 are \texttt{3\_0\_SWF\_CHD} and
\texttt{3\_1\_CLN\_for\_SWF}. From version 2025.014, \cln\ and \swf\ CHD records
in \texttt{Modflow.chd} write both a start head (the cell starting head) and an
end head (the assigned constant head). \mfus\ requires both values and
interpolates between them over the stress period so the assigned head is not
applied as an instantaneous shock. Version 2025.012 wrote only the assigned
head on those records. \gwf\ CHD records already used two heads (both equal to
the assigned value). See also the 2025.014 note in
Appendix~\ref{chapter:modifications}.

\section{3\_0\_SWF\_CHD}
Responses differ. IN-OUT series differ (max |diff| = 0.00133)

Cause: version 2025.014 began writing both start and end heads on \swf\ CHD records (USG requires both). The 2025.012 baseline wrote only the assigned head. The outlet cell (node 202) now has start and end heads both equal to the assigned value $1.000001$ (the cell starting head already matches the CHD). Completing the two-head record changes \texttt{OUT\_SWF CONST HEAD} through the run (about $0.3873$ to $0.3857$~m$^3$/s at $t=163$~s). Sibling example \texttt{3\_SWF} uses a critical-depth outlet instead of CHD and is unchanged.

\section{3\_1\_CLN\_for\_SWF}
Responses differ. IN-OUT series differ (max |diff| = 0.00415)

Cause: the same 2025.014 CHD change, for \cln. The outlet record is now a start-to-end ramp from the cell starting head to the assigned CHD $1.000001$ (they differ only in the last decimal place). The 2025.012 file had a single assigned head, which USG applied as an instantaneous shock. That produced a first-step \texttt{IN\_CLN STORAGE} pulse of about $0.00415$ and a $1\%$ mass-balance discrepancy; the ramp removes the shock.
