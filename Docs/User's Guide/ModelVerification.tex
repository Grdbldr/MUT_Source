These models verify the accuracy of \mfus\ models built using \mut\ and demonstrate its ability to capture a range of conceptual situations, from simple to complex. To rebuild the set and compare a new \mut\ release with the previous-version baseline, see Appendix~\ref{appendix:release_verification}. For version 2025.030 that comparison also checks the updated build software listed in Chapter~\ref{chapter:Installation}: \mut\ was rebuilt with Microsoft Visual Studio Community 2026 and Intel® Fortran Compiler 2026.1 on Windows 11, and the verification models were re-run against the 2025.012 baseline.
