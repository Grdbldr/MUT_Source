\label{chapter:modifications}
\label{changes:2025.022}
Changes in version 2025.022:
\begin{itemize}
\item Optional instruction {\sf original swf velocity calculation}: writes VEL \texttt{OPTIONS} / \texttt{ORIGINAL\_SWF\_VELOCITY} so \texttt{usgs\_1} uses the original HGS Manning SWF velocity; default remains face-flux reconstruction. Both methods use the smoothed SWF flow depth (\texttt{SWF\_THIK}), not depth minus depression/obstruction.
\end{itemize}

\label{changes:2025.021}
Changes in version 2025.021:
\begin{itemize}
\item Model-folder documentation: \texttt{mut\_document.py} (deployed with \texttt{mut.exe}) writes \texttt{Docs/\textit{folder}.pdf} plus sectioned Tecplot layouts after \texttt{mut \_build}; optional \texttt{tec360} PNG export and inclusion of \texttt{usgs\_1}/\texttt{mut \_post} mass-balance results
\end{itemize}

\label{changes:2025.020}
Changes in version 2025.020:
\begin{itemize}
\item General Spatio-Temporal Recharge (GSTR): named instances on \gwf, \swf\ and \cln, ArcASCII raster snapshots, timestep interpolation; existing \textsf{RCH}/\textsf{RTS} unchanged; Tecplot post-processing of applied GSTR rates
\item \gwf\ porosity echoed at build for average-linear velocity
\item Optional CLN \texttt{InfillPorosity} column; average-linear conduit velocity equals Darcy velocity divided by infill porosity when less than 1
\item MUT OC reader accepts \texttt{DARCY VELOCITY SAVE UNIT} and \texttt{LINEAR VELOCITY SAVE UNIT}
\end{itemize}

\label{changes:2025.019}
Changes in version 2025.019:
\begin{itemize}
\item Default USG \texttt{VEL} package on every build: Darcy and average-linear velocity binaries for active \gwf, \cln\ and \swf\ domains; OC \texttt{SAVE DARCY/LINEAR VELOCITY}
\item \texttt{mut \_post} reads USG velocity binaries only and writes sequential Tecplot arrays \texttt{Vx/Vy/Vz}; requires a USG-Transport build that recognizes NAM file type \texttt{VEL}
\end{itemize}

\label{changes:2025.014}
Changes in version 2025.014:
\begin{itemize}
