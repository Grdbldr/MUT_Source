\label{chapter:modifications}
\label{changes:2025.026}
Changes in version 2025.026:
\begin{itemize}
\item Model documentation is written by default after a successful \texttt{mut \_build} or \texttt{mut \_post} (\texttt{mut\_document.py --skip-export}). Instruction {\sf no model documentation} skips it for that MUT file only, so documentation can be build-only, post-only, both, or neither. Missing Python, the script, or \texttt{pdflatex} is a warning; MUT still ends with \texttt{Normal exit}. The former instructions {\sf write model documentation} and {\sf write binary tecplot output} are removed.
\item Volume-budget time series is a dedicated \texttt{GWF\_VolumeBudget.lay} (full-page XY plot with a line-map legend) rather than a frame on \texttt{GWF\_Results.lay}.
\item Release verification uses \texttt{VerificationFolder.List} (one folder name per line) in \texttt{C:\textbackslash Work\textbackslash Examples-Release}. From the \mut\ source repository, \texttt{Tools/verify\_release.ps1} runs \texttt{mut\_verify}, which executes \texttt{mut \_build}, \texttt{usgs\_1} and \texttt{mut \_post} per listed folder. See Appendix~\ref{appendix:release_verification}.
\end{itemize}

\label{changes:2025.025}
Changes in version 2025.025:
\begin{itemize}
\item Optional instruction {\sf write model documentation}: after a successful \texttt{mut \_build} or \texttt{mut \_post}, MUT runs \texttt{mut\_document.py --skip-export} and writes \texttt{Docs/\textit{folder}.pdf} plus layouts. A documented build is expanded after \texttt{\_post} even if \texttt{\_post.mut} does not repeat the instruction. Missing Python, the script, or \texttt{pdflatex} is a warning; MUT still ends with \texttt{Normal exit}. Manual \texttt{python \%USERBIN\%\textbackslash mut\_document\textbackslash mut\_document.py} remains available for PNG export.
\end{itemize}

\label{changes:2025.024}
Changes in version 2025.024:
\begin{itemize}
\item Finite-element \tecplot\ output defaults to one TecIO SZL file per dataset (\texttt{.tecplot.szplt}). Post-processed \gwf/\swf/\cln\ results and velocity are a single file with all output times (later zones share coordinates and connectivity). Optional {\sf write ascii tecplot output} restores ASCII \texttt{.tecplot.dat}. Scatter, custom-label, volume-budget and restart files remain ASCII. The obsolete instruction {\sf write binary tecplot output} is ignored.
\item Release-verification appendix: \texttt{Tools/verify\_release.ps1} runs the verification models in \texttt{C:\textbackslash Work\textbackslash Examples-Release} against \texttt{Examples-Base}, exports \texttt{BatchComparisonPlots.lay} frames, and includes them as Appendix~\ref{appendix:release_verification}. Volume-budget comparison is index-wise when \texttt{TOTAL TIME} lists match, so duplicate dumps at stress-period boundaries (e.g.\ Abdul) are not false-flagged. Remaining IN--OUT differences in \texttt{3\_0\_SWF\_CHD} and \texttt{3\_1\_CLN\_for\_SWF} versus a 2025.012 baseline are the 2025.014 \cln/\swf\ CHD start-to-end head ramps. Selected inputs are published to \texttt{MUT\_Examples} with \texttt{ToRepos.bat} (never the reverse).
\end{itemize}

\label{changes:2025.014}
Changes in version 2025.014:
\begin{itemize}
\item \texttt{chd zone name}: tag CHD groups with \texttt{AUXILIARY CHDZONE} and a \texttt{.chdzone} map for separate LST/Tecplot budget terms
\item \texttt{cln from structure file}: build \cln\ domain from mesh-intersection output; companion \texttt{.xyzList} written
\item CLN mesh intersection hardening: collapse duplicate face hits, remove zero-length segments, preserve network links; improved \texttt{feprism}/\texttt{febrick} prism-mesh support
\item \cln\ and \swf\ CHD records written as start-to-end head ramps (USG requires both heads; start is the cell starting head, end is the assigned CHD). This is why examples \texttt{3\_0\_SWF\_CHD} and \texttt{3\_1\_CLN\_for\_SWF} differ from a 2025.012 baseline; the critical-depth sibling \texttt{3\_SWF} does not. See Appendix~\ref{appendix:release_verification}.
\end{itemize}
